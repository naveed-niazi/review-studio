## Notifications that work in the background

- Native macOS alerts for reviews awaiting approval, blocking reviews, failed operations, and connection issues. Alerts distinguish network/DNS, provider service, account, and rate-limit problems using existing connection diagnostics.
- Dock badges and menu-bar counts show outstanding items. Counts clear as issues resolve, rather than when the window opens.
- Background monitoring continues with the window closed. An exited or unresponsive review engine raises an alert and keeps the desktop available for restart.
- Grouped alerts, persistent duplicate suppression, optional 30-minute reminders, and connection recovery notices avoid a notification for every retry.
- Settings control alert categories, sounds, reminders, and badges. A test button and macOS settings shortcut help diagnose permission or delivery problems.
- Notification text keeps private repository names, PR titles, review contents, and raw logs out of Notification Center.

## Upgrade notes

Existing repositories, prompts, review history, runner settings, and merge rules are preserved. Notifications and badges default to on; sound defaults to off. Allow notifications and badges for Review Studio in macOS System Settings. Focus may suppress banners. The app must remain running to monitor reviews; browser-only mode does not send native Mac notifications.

Mac previews now use an ad-hoc signature with Review Studio's own bundle identity. Native notification delivery was verified in the packaged app. These builds still lack Apple Developer ID signing and notarization, so Gatekeeper and login-item limitations remain. See the [notification guide](https://github.com/naveed-niazi/review-studio/blob/v1.3.0/docs/configuration.md#notifications-and-attention-count).
